📖 Guide d'utilisation

  • Seuils : Les jauges se mettent à jour. Rouge <30%, Jaune 30-50%, Vert >50%.
  • Mission : Système de "Snapshot". Photographiez le stock, ajustez en vol, et générez un rapport différentiel.
  • Images : Dans Paramètres, cliquez sur l'icône image pour charger/recadrer. (Drag & Drop supporté).
  • Medbay : Module modulaire pour gérer les lits, patients et MedGel.
  • Sauvegardes : Fichier JSON local contenant toutes vos données.
